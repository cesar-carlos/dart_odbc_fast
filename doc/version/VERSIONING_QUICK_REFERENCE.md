# Versioning quick reference

The authoritative decision table and compatibility policy are in
[Versioning strategy](VERSIONING_STRATEGY.md#canonical-semver-rule-post-100).
Read the current package version from [pubspec.yaml](../../pubspec.yaml).

For a release, follow [Release automation](RELEASE_AUTOMATION.md), including
validation, immutable tags and automated publication. Use the
[Changelog template](CHANGELOG_TEMPLATE.md) for release notes.
